# 1/8 Analysis frame (summary)

- Degrees: Primary(weekly) > Intermediate(daily) > Minor(4H) > Minute(15/5m) > Sub-min(1m).
- Default simple ABC; promote only on rule break. Inclusion/ratio(0.236-0.618)/alternation must pass.
- 0.66 = box anchor, 0.618 = correction target, 0.382 = shallow. Adopt only on 3-way overlap within 1%.
- 1m RSI never alone; need 1m extreme + 5m divergence + Minor support.
- Count on SOXX, convert with SOXL=SOXL0*(X/X0)^3, recent anchors only.
