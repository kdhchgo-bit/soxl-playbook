# 7/8 Exceptions

- Gap+short-cover is not impulse: no chase, raise high only.
- Session badges (Weekend Closure/Overnight/Pre-Market/Market Open) are phase labels, not halts.
- Max Long reject -> stop there, retry only after top +0.02.
- Hydration placeholders (--Mark Price--) -> re-snapshot same tab.
- All tabs CDP timeout -> openTab same URL. Remembered targetIds expire.
